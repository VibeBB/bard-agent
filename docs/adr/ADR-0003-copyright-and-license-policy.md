# ADR-0003: 著作権とライセンスの方針

> ステータス: Accepted
> 日付: 2026-09-20

## コンテキスト

bardは歌詞と旋律を生成する。LLMは学習した既存楽曲の歌詞・旋律を再現しうるため、
生成物が第三者の著作物を含むリスクがある。また、音楽ツールにはGPL系のものが多い。

## 決定

### 生成物

1. 歌詞と旋律は完全な自作とする。既存楽曲の歌詞・旋律の引用、翻案、パロディ、
   「〜風に」という実在アーティストの名指し模倣を禁止する。
2. 伝統曲（公有）の旋律であっても0.1では使わない。歌はすべてオリジナルの旋律とする。
3. 風刺（`satire`モード）の対象はコード、バグ、仕組み、抽象化した役割に限り、実在の人物・
   団体・製品を嘲笑しない。会話に登場する人名は歌に入れず、役割名（「見張り番」「旅の
   レビュアー」等）へ置き換える。
4. 提案の`originality`（自作歌詞・自作旋律・アーティスト模倣なし・実在人物嘲笑なし）が
   すべて`true`でなければ検証器は描画しない。これは宣言であり、検証器は歌詞の内容を
   照合できない。宣言の責任はbardのpromptで明示し、criticは既知の歌詞・旋律に似ている
   疑いを所見として報告する。
5. 商標・作品固有の用語（特定のTRPG製品名やその固有名詞）を製品名・設定名として使わず、
   一般名詞のbardと自作の語彙で構成する。
6. 生成物のprovenanceに`license: BSD-3-Clause`と`authority: none`を記録する。本リポジトリに
   同梱するサンプル歌はBSD-3-Clause（リポジトリと同一）で配布する。

### 依存コード

| 対象 | ライセンス | 判断 |
| --- | --- | --- |
| Python標準ライブラリだけの自作描画器 | BSD-3-Clause（本リポジトリ） | 採用 |
| music21 | BSD-3-Clause（corpusは別ライセンス） | 不採用（依存が重い） |
| mido / pretty_midi | MIT | 不採用（stdlibで足りる） |
| mingus | GPL | import結合不可 |
| LilyPond / abcm2ps | GPL | import結合不可。subprocess実行は将来のADRで検討 |
| FluidSynth | LGPL-2.1 | subprocess実行は将来のADRで検討 |
| FluidR3_GM / MuseScore_General SoundFont | MIT | 将来の音声化で採用可 |
| GeneralUser GS | 独自許諾（サンプル出所の不確実性を作者が明記） | 不採用 |

外部由来コードを含むファイルでは元のライセンス表記と帰属を維持する。自作ファイルへ
無関係な第三者著作権表記を追加しない。

## 影響

- bardの表現力は自作の範囲に限定される。利用者が既存曲の使用を求めた場合、bardは断り、
  代わりに同じ雰囲気のオリジナルを提案する。
- 生成物の著作権帰属はLLM提供者の利用規約と各国法に依存する。本リポジトリは帰属を
  保証せず、provenanceで生成経路を追跡可能にするに留める。
