# ADR-0006: ask_oracle / tom_consult 不採用

> ステータス: Accepted
> 日付: 2026-09-22

## コンテキスト

SDKにはタスク境界の外側に2つのコンサルト系ツールがある。

- `ask_oracle`（`AskOracleTool`）: 保存された`oracle`プロファイルへ
  ワンショットで助言を求めるツールレスのサブエージェント。
- `tom_consult`（`TomConsultTool`）: 会話をインデックスしてユーザーモデルを
  構築し、パーソナライズされた助言を返すツール。

いずれも呼び出したエージェントへ自由形式の助言を返す。

## 決定

このリポジトリではどちらも採用しない。

- `ask_oracle`の助言は非決定的でプロベナンスを持たない。bardの契約では
  判定はvalidatorと提案契約だけが持ち、criticの観察も構造化された形で
  記録される。何を・どのプロファイルに聞いたかが記録されない助言呼び出しは
  交差検証できず、criticとStage 8スコア検査の明示的な観察レーンで用途は
  足りる。
- `tom_consult`は会話を横断する永続的ユーザーモデルを構築するため、
  プラグインの境界外の状態付きサイドチャネルであり、bardが必要としない。

## 結果

- 新しいツールは登録しない。エージェントのツール面は`task`・SDKの
  file_editor系・bard MCPツールのまま維持する。
- 将来「第二意見」が必要になった場合、`ask_oracle`は記録プロベナンスの
  要件（profile・prompt・応答ハッシュの記録）を満たす形で再検討する。
